## 1. 用户画像与使用场景

### 1.1 画像一：个人开发者（日常编码）

```
角色: 全栈开发者
场景: 日常功能开发、Bug 修复、代码重构
交互方式: CLI 终端 或 IDE 集成
核心诉求:
├── 快速理解代码库并做出修改
├── 自动运行测试验证修改
├── 安全地执行 shell 命令
├── 在长会话中保持上下文连续性
└── 能搜索网络获取技术文档和方案

典型工作流:
1. 启动 Agent，描述需求
2. Agent 读取相关代码，理解结构
3. Agent 制定修改方案，逐步执行
4. Agent 运行测试验证修改
5. 用户确认，Agent 提交代码
```

### 1.2 画像二：DevOps 工程师（CI/CD 集成）

```
角色: DevOps / 平台工程师
场景: 自动化代码审查、PR 处理、部署管线
交互方式: API / CI/CD 管线嵌入
核心诉求:
├── 无人值守自动执行
├── 严格的权限控制和沙箱隔离
├── 可编程的 Agent 工作流
├── 完善的日志和可追溯性
└── 定时任务和事件驱动能力

典型工作流:
1. PR 创建 → Webhook 触发 Agent
2. Agent 自动审查代码变更
3. Agent 生成审查意见并提交评论
4. CI 失败 → Agent 自动分析失败原因
5. 每日定时任务检查代码库健康
```

### 1.3 画像三：技术团队（多 Agent 编排）

```
角色: 技术 Lead / 架构师
场景: 大型特性开发、跨模块重构
交互方式: 多 Agent 并行 + 协调器
核心诉求:
├── 将复杂任务分解到多个专业 Agent
├── 前端/后端/测试 Agent 并行工作
├── 结果聚合与冲突检测
├── 成本可控（按任务分配 token 预算）
└── 使用技能库标准化团队操作流程

典型工作流:
1. 主 Agent 分析任务，分解为子任务
2. 前端 Worker / 后端 Worker / 测试 Worker 并行执行
3. 各 Worker 在隔离上下文中独立工作
4. 结果摘要汇报给主 Agent
5. 主 Agent 聚合结果，检测冲突，提交
```

### 1.4 用户画像汇总

| 画像 | 角色 | 场景 | 交互方式 | 关键需求域 |
|------|------|------|---------|-----------|
| 个人开发者 | 全栈开发者 | 日常编码、Bug 修复 | CLI / IDE | FR-1~5, FR-7, FR-8, FR-14 |
| DevOps | 平台工程师 | 代码审查、部署 | API / CI/CD | FR-5, FR-9, FR-11, FR-13 |
| 技术团队 | 技术 Lead | 大型特性、跨模块 | 多 Agent | FR-6, FR-10, FR-12 |

## 2. 功能需求（14 域 / 82 项）

### FR-1: Agent 循环引擎

| ID | 描述 | 优先级 | 验收标准 |
|----|------|--------|---------|
| FR-1.1 | 流式 ReAct 循环（感知→推理→行动→观察→循环） | P0 | Agent 能通过多轮工具调用完成任务 |
| FR-1.2 | 流式中途检测 tool_use 块并即时执行 | P0 | 不需等待完整响应即开始工具执行 |
| FR-1.3 | 单次 API 多个 tool_use 块（顺序执行） | P1 | 单次响应含多工具调用时依次执行 |
| FR-1.4 | 无 tool_use 时终止循环 | P0 | 模型输出纯文本时停止循环 |

## 4. 优先级矩阵与迭代边界

### 4.1 四象限优先级矩阵

```
┌──────────────────────────────────────┬──────────────────────────────────────┐
│  P0（MVP, 第 1-2 周）                 │  P1（第 3-4 周）                      │
│                                      │                                      │
│  FR-1.1 流式 ReAct 循环               │  FR-2.4 MCP 动态工具注册               │
│  FR-1.2 流式中途检测 tool_use          │  FR-10.1~4 技能系统核心                │
│  FR-1.4 无 tool_use 终止               │  FR-14.1~3 Web搜索/URL抓取/Git搜索    │
│  FR-2.1 6 个核心工具                   │  FR-5.4~6 沙箱+策略引擎+审批           │
```
